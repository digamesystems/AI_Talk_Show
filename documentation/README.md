- **`tic_scanner.py`** (now in `/tools`, not this folder — cross-referenced here since it's used on files that live here) — a command-line tool (`python tools/tic_scanner.py documentation/path/to/essay.md`, run from the repo root) that flags candidate AI-writing tics in a markdown draft: em-dash density, inflated vocabulary, hedging/meta-commentary phrases, the "not just X, it's Y" formula, frozen-verb nominalizations, and long sentences. Grew out of the manual em-dash and phrase audits done by hand on Essay 3 and Essay 4; automatically excludes citation lines and each file's own "Revision log" section from scanning, since both would otherwise pollute the results (the revision log especially — it's prose *about* these tics, written using the exact words being searched for). A heuristic flagging tool, not a judge — every hit still needs a human call.
